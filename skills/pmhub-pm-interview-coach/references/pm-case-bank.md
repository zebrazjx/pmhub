# PM Case 训练库

Case 用于测试判断过程，不是寻找唯一答案。优先根据目标 JD 改写场景；不要冒充目标公司的真实内部问题或数据。

## 通用发题格式

```markdown
背景：{产品／业务与阶段}
任务：{需要候选人做出的判断}
已知：{最少必要信息}
限制：{时间、资源、合规或技术约束}
你可以先问我 3—5 个澄清问题。
```

只有用户提出合理问题时，才逐步提供预先设定的补充信息。没有设定的数据应回答“未知”，并观察用户如何处理不确定性。

## C 端产品

1. 新用户首日完成率下降，如何定位并设计下一步？
2. 为低频工具设计留存策略，如何避免为了 DAU 制造无效打扰？
3. 一个核心流程加入 AI 助手，如何验证是否真的降低任务成本？

观察：用户细分、任务频率、漏斗、体验与业务护栏。

## B 端／平台

1. 多部门要求互相冲突，如何定义首版权限系统？
2. 内部平台采用率低，业务团队仍使用表格，如何判断是产品、迁移还是激励问题？
3. 三个大客户要求定制，如何决定平台化边界？

观察：角色与流程、配置／定制、权限审计、交付成本和变更管理。

## 增长与商业化

1. 付费转化提升但退款上升，是否继续实验？
2. 获客成本上升，如何拆解问题并选择实验？
3. 免费额度应如何调整，兼顾激活、成本和付费？

观察：指标树、实验设计、归因、单位经济与护栏。

## AI 应用／Agent

1. 客服 Agent 的任务完成率不错，但人工投诉增加，如何诊断？
2. 知识库每天更新且有多级权限，如何设计 RAG 方案和验收？
3. Agent 要执行可退款操作，如何决定自主程度、确认点和回滚？
4. 模型升级使质量提高但成本翻倍，如何做产品决策？

观察：任务边界、评测集、幻觉、权限、延迟、成本、人在回路与失败恢复。

## 数据与评测

1. 离线评测提高，线上满意度下降，可能发生了什么？
2. 标注员对“好答案”分歧很大，如何修订评测体系？
3. 长尾用户投诉严重但总体指标稳定，如何处理？

观察：指标有效性、样本分布、分群、标签规范、裁决和反馈闭环。

## 跨团队与优先级

1. 算法团队认为尚不能上线，业务方坚持赶节点，你如何推进？
2. 上级临时加入高优需求，会冲击已承诺目标，如何处理？
3. 你没有管理权，但需要三个团队在两周内配合，如何降低协调风险？

观察：共同目标、约束透明、选项、决策机制、承诺边界与升级路径。

## 变式旋钮

复训时只改变 1—2 个变量：

- 用户：大众用户 → 专家／未成年人／企业管理员；
- 阶段：0→1 → 规模化 → 降本；
- 资源：两个月 → 两周；
- 数据：充分 → 稀疏／偏差／不可共享；
- 风险：普通建议 → 金融／医疗／退款等高风险动作；
- 技术：稳定 API → 高延迟／不稳定／模型不可控；
- 组织：单团队 → 多部门／客户共建；
- 目标：增长 → 收益／合规／可靠性。

变式必须保持与原缺口相关，不要单纯增加信息量。
