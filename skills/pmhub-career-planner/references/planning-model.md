## 3. 机会决策卡

必须附：

- 硬约束冲突；
- 放弃的第二好选项；
- 最大未知；
- 哪条新证据会改变当前排序；
- 决定截止日和重新打开决定的条件。

## 4. 可逆性分级

- `双向门`：低成本可撤回，例如参加一次信息访谈、做小项目；优先快速行动。
- `中等切换`：需要数周或数月恢复，例如选择一个学习项目；设检查点。
- `单向门`：高现金流、地域、签证、声誉或关系代价，例如裸辞、跨国搬迁；先做现实检验和下行情景。

不要把所有决定都拖成单向门，也不要用“先试试”淡化真实不可逆成本。

## 5. 现实检验菜单

- 与 3 位真实从业者做结构化信息访谈，并寻找反例；
- 完成目标岗位的一段真实任务，而不是只看课程；
- 审查 20—30 条真实 JD，统计核心任务和硬门槛；
- 做一个带评测和复盘的作品项目；
- 争取当前组织内的桥接任务；
- 小规模投递并观察具体漏斗，不把几次结果外推为市场规律；
- 影子工作、短期协作、社区贡献或开源贡献。

每个检验应写明：要验证的假设、样本、通过／失败标准、截止日期和下一步。
