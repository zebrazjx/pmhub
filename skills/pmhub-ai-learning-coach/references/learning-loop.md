# 学习闭环与评测规则

## 1. 知识单元

一个单元应小到能在 15—60 分钟内完成一次主动练习，例如“判断某知识问答场景是否需要 RAG”，而不是“学会 RAG”。每个单元只保留一个主目标。

## 2. 基线抽样

不要先给教程再测试。先从以下三类中各选一个最小任务：

- **解释题**：请用户不用术语堆砌地说明机制、边界和一个反例；
- **决策题**：给出目标、数据、成本、延迟、权限等约束，让用户选方案；
- **实作题**：让用户设计流程、实验、测试集或排障顺序。

对已有作品，用“展示产物—解释关键决定—指出失败—复现实验”替代基础问答。

## 3. 费曼式循环

### 讲解

使用四段最小结构：

1. 它解决什么问题；
2. 输入如何变成输出；
3. 哪个假设最容易失效；
4. 在目标岗位中需要做什么决定。

### 复述

指定受众和限制，例如：“请在 120 字内向不懂算法的客服负责人解释，为什么增加向量库不一定减少幻觉。”不要让用户照抄刚才的小标题。

### 找缺口

按以下标签反馈，不用“差不多正确”掩盖问题：

- `遗漏`：关键环节未提及；
- `混淆`：两个机制或指标被当成一个；
- `因果跳步`：结论缺少中间条件；
- `边界缺失`：没有说明何时不适用；
- `证据不足`：用了断言但没有实验或数据；
- `表达负担`：术语多于必要信息。

先肯定准确部分，再指出最多三个最高影响缺口。重讲只覆盖这些缺口。

### 实作

优先选择可观察任务：

- 画系统链路并标注风险点；
- 比较两个方案并给出淘汰条件；
- 写 10—30 条最小评测集；
- 跑一个基线并分类失败；
- 为一次高风险工具调用设计确认、回滚和审计。

## 4. 掌握 Rubric

| 状态 | 可观察表现 | 下一步 |
|---|---|---|
| 认识 | 能认出术语，但解释依赖原文 | 最小讲解＋当天复述 |
| 可解释 | 链路基本正确，能说边界和反例 | 加约束决策题 |
| 可决策 | 能权衡至少两种方案并列淘汰条件 | 做最小实作 |
| 可实作 | 产物可运行／审查，能定位主要失败 | 建立基线和迭代 |
| 可举证 | 有版本、测试集、结果和失败复盘 | 转成作品证据并做迁移题 |

只有在用户无材料完成、或面对新情境仍能作答时，才升级状态。一次答对但理由偶然正确，不足以升级。

## 5. 检索练习

每次复习包含：

1. 一个无提示核心回忆题；
2. 一个改变约束的迁移题；
3. 一个与旧主题连接的判断题；
4. 一条“我最可能在哪犯错”的自我监控问题。

先收答案，再显示反馈。选项题可用于快速抽样，但至少保留一道生成式回答。

## 6. 间隔调整

默认间隔是 1、3、7、14、30 天，不是固定承诺。按表现调整：

| 表现 | 处理 |
|---|---|
| 准确、理由充分、能迁移 | 下一间隔约翻倍 |
| 答对但理由脆弱 | 保持原间隔，换情境再测 |
| 遗漏关键条件 | 24—72 小时内重测对应缺口 |
| 高置信错误 | 当轮纠错，24 小时内无提示再测 |
| 实作失败 | 先诊断失败类型，不用重复背定义代替修复 |

## 7. 学习科学依据

这些来源解释方法选择，不是要求在普通输出中长篇引用：

- Roediger & Karpicke (2006), *Test-Enhanced Learning*, Science, DOI: [10.1126/science.1127335](https://doi.org/10.1126/science.1127335)。支持用主动检索而非反复重读检验长期保持。
- Cepeda et al. (2006), *Distributed Practice in Verbal Recall Tasks*, Psychological Bulletin, DOI: [10.1037/0033-2909.132.3.354](https://doi.org/10.1037/0033-2909.132.3.354)。支持跨时间分散练习。
- Dunlosky et al. (2013), *Improving Students’ Learning With Effective Learning Techniques*, Psychological Science in the Public Interest, DOI: [10.1177/1529100612453266](https://doi.org/10.1177/1529100612453266)。综述练习测试与分散练习等方法的效用。

“费曼式复述”在本 Skill 中表示：简化解释、暴露缺口、回到材料、重讲并应用；不要把它描述成经过统一验证的临床或心理测量工具。
